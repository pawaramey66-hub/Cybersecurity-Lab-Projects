# 🔐 Cybersecurity Lab Projects

Hands-on cybersecurity projects completed in an isolated home virtual lab while learning network security, penetration testing concepts, traffic analysis, and Android application security.

> **Lab scope:** All testing is performed only against intentionally vulnerable virtual machines and applications in a private, authorized environment.

## 🧪 Projects

| # | Project | Focus | Tools |
|---|---|---|---|
| 01 | [Network Mapping & Service Discovery](projects/01-nmap-network-scanning/) | Host discovery, ports, services, OS detection | Nmap, Kali Linux, VMware |
| 02 | [Metasploit Lab & Vulnerability Analysis](projects/02-metasploit-vulnerability-analysis/) | Vulnerability validation, troubleshooting, remediation | Metasploit, Kali Linux, VMware |
| 03 | [Network Traffic Analysis](projects/03-wireshark-traffic-analysis/) | HTTP traffic, packet inspection, security observations | Wireshark, Kali Linux |
| 04 | [Android Static Analysis](projects/04-android-static-analysis/) | Mobile application security assessment | MobSF, Docker |

## 🛠️ Skills Demonstrated

- Network reconnaissance and service enumeration
- Vulnerability assessment in controlled lab environments
- Metasploit Framework fundamentals
- Packet capture and protocol analysis with Wireshark
- Android application static analysis
- VMware-based cybersecurity lab setup
- Security documentation and technical reporting

## 🖥️ Lab Environment

- **Hypervisor:** VMware Workstation Pro
- **Primary OS:** Kali Linux
- **Target systems:** Intentionally vulnerable virtual machines/apps
- **Network:** Private virtual lab network

## 🎯 Learning Goals

This repository documents my practical cybersecurity learning journey and focuses on understanding how vulnerabilities work, how they can be detected, and how systems can be secured against them.

## ⚠️ Ethical Use

The techniques documented here are intended for authorized security testing, education, and defensive learning. Do not test systems, accounts, networks, or applications without explicit permission.
